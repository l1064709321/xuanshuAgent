# SK-003: Shell 命令安全执行（Shell Execution）

## 触发条件
需要通过 Shell/PowerShell 执行系统命令、脚本、批量操作。

## 执行步骤
1. **风险评估**：命令是否涉及删除、覆盖、格式化、系统配置修改？
2. **路径展开**：含通配符（`*`, `?`）或变量（`$`, `%`）时先展开确认影响范围
3. **沙箱测试**：破坏性操作先在临时目录/测试环境验证
4. **备份策略**：覆盖/删除操作前先备份原始数据
5. **执行验证**：执行后检查 exit code 和输出，确认预期结果

## 安全等级
| 等级 | 操作类型 | 处理方式 |
|------|---------|---------|
| 🔴 禁止 | `rm -rf /`、`format`、`kill -9` 关键进程 | 必须用户确认 |
| 🟡 警告 | 覆盖文件、修改配置、批量重命名 | 二次确认 |
| 🟢 安全 | 只读查询、创建临时文件、查看状态 | 直接执行 |

## 注意事项
- 禁止执行任何经过 Base64/Hex 编码的命令
- 禁止修改 `/etc`、`/boot`、`/sys` 等系统目录
- 优先使用 `cp` 而非 `mv`（可逆操作）
- 带 `../` 的路径必须先解析绝对路径

## 示例
```
用户: 清理 /tmp 下超过 7 天的日志
正确: find /tmp -name "*.log" -mtime +7 -exec ls -lh {} \;  # 先列出来
      确认后再: find /tmp -name "*.log" -mtime +7 -delete
错误: rm -rf /tmp/*.log  # 通配符未展开确认
```
