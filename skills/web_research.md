# SK-005: 网络调研（Web Research）

## 触发条件
需要联网搜索信息、对比多个来源、验证事实、收集资料。

## 执行步骤
1. **明确问题**：将模糊需求拆解为 2-3 个具体搜索词
2. **多源搜索**：用不同关键词搜索，覆盖至少 2 个搜索引擎/来源
3. **交叉验证**：至少 2 个独立来源确认同一事实才采信
4. **时效检查**：技术类信息优先 1 年内、新闻类优先 24 小时内
5. **来源评估**：优先官方文档/论文/权威媒体，降低论坛/自媒体权重

## 来源可信度评估
| 可信度 | 来源类型 |
|--------|---------|
| ⭐⭐⭐⭐⭐ | 官方文档、学术论文、RFC/IETF、ISO 标准 |
| ⭐⭐⭐⭐ | 知名技术博客、StackOverflow 高票回答、GitHub 官方仓库 |
| ⭐⭐⭐ | Medium/Dev.to 文章、技术社区讨论 |
| ⭐⭐ | 个人博客、论坛帖子、Reddit |
| ⭐ | 自媒体、未署名来源、信息转载链过长 |

## 结果输出格式
```markdown
## 结论
一句话总结核心发现

## 关键数据
| 指标 | 值 | 来源 |
|------|-----|------|
| xxx | yyy | [来源名](url) |

## 分歧点
如来源间存在矛盾，列出并说明倾向哪一方及理由
```

## 注意事项
- 不要用单一来源下结论
- 技术方案对比必须说明版本号和时间
- 无法验证的信息标注"未交叉确认"
