# SK-006: 文件操作规范（File Operations）

## 触发条件
批量创建、移动、复制、删除、重命名文件或目录。

## 执行步骤
1. **范围确认**：列出所有受影响文件，确认数量和总大小
2. **命名规范**：文件名统一使用 `snake_case`，日期格式 `YYYY-MM-DD`
3. **路径安全**：检查路径是否包含 `../` 穿越，是否在允许的工作区内
4. **先测后改**：批量操作前用 `--dry-run` 或 `echo` 模拟
5. **操作日志**：记录操作类型、源路径、目标路径、时间戳
6. **结果验证**：操作后检查文件数量、大小是否匹配预期

## 安全规则
| 规则 | 说明 |
|------|------|
| 禁止覆盖 | `write_file` 写入已存在文件会自动重命名，不要强制覆盖 |
| 禁止系统路径 | 不操作 `/etc`、`/boot`、`/sys`、`/proc` 等系统目录 |
| 禁止批量删除 | 单次删除不超过 50 个文件，通配符删除需用户确认 |
| 优先回收站 | 删除操作优先移入回收站，避免永久删除 |

## 产出物规范
- 中间文件 → `temp/` 目录
- 最终产出 → `output/` 目录
- 命名格式：`{项目前缀}_{日期}_{描述}.{扩展名}`
- 禁止产出物写入系统临时目录（如 `/tmp`）

## 示例
```
用户: 把 downloads 的图片按日期整理到 photos 目录
正确流程:
1. ls downloads/*.{jpg,png} → 确认 47 张图片
2. mkdir -p photos/2024-01 photos/2024-02 ...
3. 逐月移动: mv downloads/2024-01-*.jpg photos/2024-01/
4. 验证: find photos -type f | wc -l → 47，匹配
```
